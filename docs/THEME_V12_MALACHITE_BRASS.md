# 主题 v12 · 孔雀石 × 黄铜（Malachite & Brass）

> 起因：v11「Emerald Atelier」被反馈「不是 太单调了」。
> v11 的做法是把整站压进单一 158° 色相带、关掉所有彩色光斑、缩略图统一成同款灰绿。
> 结果「高级」是有了，「单调」也有了——一个没有纵深、没有材质、没有焦点的单色界面。

## 1. v11 单调的三个具体原因

| 原因 | 位置 | 后果 |
|---|---|---|
| 所有颜色只在 158° 一个色相带里 | `theme-v11.css` `:root` | 无法用色相区分信息层级 |
| 四层光斑全被 `display:none` 关掉 | `.wm-bg-far/.wm-bg-mid/.wm-bg-mist` | 背景是一块平涂的骨白 |
| 缩略图从 v11 起就没显影 | `.wm-thumb[data-thumb]` 把容器压成 46px 圆 | 每张卡都是「白卡 + 小圆点」 |

第三条是隐藏的元凶：`.wm-thumb` 自带 `data-thumb` 属性，`[data-thumb]` 规则本意是给
「印章」用，结果命中了容器本身，150px 的生态渐变被框进 46×46 的圆里。

## 2. v12 的解法：加三个维度，不加杂乱

### 2.1 色相纵深（四个色相，只有一个是主角）

| 角色 | 色相 | 令牌 | 用途 |
|---|---|---|---|
| 主锚 | 158° 祖母绿 | `--acc #0B6B4B` | 主操作、选中、关键数值 |
| 副调 | 178° 青瓷 | `--teal #246B63` | 面板标题、次级选中、同步状态 |
| 金属 | 42° 黄铜 | `--brass #8A6320` / `--brass-deco #C9A961` | 关键数字、发丝线、卡片顶线、印章边框 |
| 底 | 38° 暖纸 | `--bg #F4F1E8` | 画布，替掉冷调骨白 |

绿色仍占大面积，青/金只做「贵金属点缀」。这样既有层次，又不会回到 v10 的撞色。

### 2.2 材质

- 背景四角光雾：左上绿、右上金、右下青、左下砂；雾气浓度 0.34–0.50，肉眼可见但不脏。
- 制图网格：68px 坐标格，只在顶部与右侧显影（`mask-image` 径向渐隐），像工作台图纸。
- 孔雀石斜纹：118° 细密斜纹叠在生态渐变上（`repeating-linear-gradient` 与渐变写在同一层）。
- 纸面噪点：3% 分形噪点，压掉数码平面感。
- `FORGE` 衬线水印：138px、5.8% 浓度，压在 hero 后面。

### 2.3 焦点

整页只有一个深色锚点（品牌印章 + 深绿状态条），金色只出现在「数字 / 发丝线 / 卡片顶线」。
眼睛因此有落点，而不是在浅色里漂。

## 3. 组件映射

| 组件 | v11 | v12 |
|---|---|---|
| 卡片 | 纯白平面 + 灰边框 | 白→暖白渐变 + 顶部 3px 金线 + 悬停金边框 |
| 缩略图 | 46px 圆（bug） | 168px 三色宝石渐变 + 斜纹 + 48px 白印章 |
| 主按钮 | 实色深绿 | 三段渐变 + 顶部黄铜内高光 + 悬停流光 |
| 状态条 | 淡砂（几乎看不见） | 深祖母绿 + 金发丝线 |
| 品牌印章 | 淡绿底绿字 | 深绿实心 + 金边 |
| 生态地形 | 荧光薄荷 `#6EE7A8` | 莫兰迪 `#9DBA86` 一带 |
| 天空 | hue 0.44 青绿 | hue 0.29 暖白微绿 |

## 5. 实测对比度（Edge 1440×900，计算样式取值）

浅色 19 项：15 项直接 PASS（4.78–14.57:1）；4 项因背景是渐变、审计脚本只能读到
`backgroundColor`，手工按合成色计算为 5.09–6.12:1，均过 AA。

夜间 17 项全部 PASS，区间 8.72–17.93:1。

## 6. 取舍

- **不加 DOM**：所有纵深靠背景层、伪元素与既有元素的 `::before/::after` 实现，
  没有新增节点，交互逻辑一行未动。
- **不动布局**：v11 已修的 hero 栅格、顶栏防折行、画布铺满等全部保留。
- **3D 视口降饱和**：从荧光薄荷改成暖纸台面。理由是「工作台的台面就该是中性色，
  彩色属于台上的造物」；否则 UI 与场景会互相抢戏。

## 7. 已知限制

- `FORGE` 水印在 <900px 会压到主按钮，已由 `overflow:hidden` 裁切，但不随内容重排。
- 生态地形色集中在 `world.js` / `biomes.js` / `biome-pro.js` 三处，改色需同步（当前已一致）。
- 夜间模式下 3D 场景亮度仍由真实感渲染控制，不受 CSS 影响。
