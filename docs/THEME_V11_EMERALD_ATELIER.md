# 主题 v11 · Emerald Atelier（深祖母绿 × 骨白）

> 替换 v10 的「WorkBuddy 荧光薄荷绿」。v10 的问题不是绿色不对，而是**只有一种绿、且全用在中高明度上**：
> 页面底色、按钮渐变、卡片缩略图、图腾字全是 400–500 号亮绿，结果是「一层绿纱」——没有层次、
> 没有重心，UI 控件和 3D 场景抢同一档明度，看久了显得廉价。

---

## 1. 设计依据：ima 知识库提取到的三条结论

检索路径：ima「超级学习机」知识库 → 关键词 `配色 / UI 设计 / 设计流程`，命中 3 篇 2025 年 UI 方法论
（《生成 732 个 UI 后总结的最佳 AI 设计流程》《如何通过 AI 提示打造惊艳 UI 设计》《10 倍 UI》）。

| # | 原文结论 | 落到本项目的做法 |
|---|---|---|
| 1 | AI 生成设计最典型的「模板感」来源是**「那种奇妙的蓝紫渐变」**与高饱和撞色渐变按钮 | 主按钮取消 `linear-gradient(135deg, gold, gold2)`，改**实色深绿 + 顶部 1px 内高光** |
| 2 | 摆脱模板感要靠**设计语汇**：typography / layout / framing / color palette 分层，而不是堆装饰 | 建立四层令牌：画布（骨白）→ 表面（纯白）→ 墨色（近黑绿）→ 单一强调色（深祖母绿） |
| 3 | 强调色要**克制**，靠排版与留白撑质感；配色方案（color palette）可一键替换以形成个性 | 强调色面积压到 < 8%，只用于主操作 / 选中 / 关键数值；提供 6 套同色相皮肤（见 §4） |

补充：知识库里**没有**现成的色值表（106 + 1631 条资料以机器人研报、教材、AI 工具文为主），
因此色值由上述三条原则 + WCAG 反推得出，而非照搬。

## 3. 组件映射（关键改动）

| 组件 | v10 | v11 |
|---|---|---|
| `.primary` / `.cta-gold` | 亮绿渐变 + 大范围 glow | 实色 `--acc` + `inset` 顶高光 + 冷绿墨投影 |
| `.mode.active` | 亮绿渐变底 + 深字 | 深绿实底 + 近白字 |
| `.wm-hero` | 标题被 `width:100%` 的按钮挤成两行 | grid `1fr auto`，按钮按内容宽度；标题上方 34×3px 绿色短线 |
| `.wm-card` | 白卡 + 淡绿缩略图 + 角落大字 | 白卡 + 150px 莫兰迪生态缩略图 + 居中图腾章（44px 圆）+ 悬停抬升 |

| `.wm-empty` | 朱砂印章 + 亮绿标题 | 细描边印章 + 墨色标题；世界数为 0 时隐藏「新建卡」，避免双 CTA |
| 世界管理背景 | 4 层彩色光斑 + 雾 | 单一极淡天光 + 3% 噪点纸纹（`::after` SVG turbulence） |

| 向导图标 | emoji（🎯🧱🎨🐲）混入红橙蓝 | 章节改汉字序号「壹贰叁肆伍」；选项 emoji 统一 `grayscale` 降为墨色符号 |

## 5. 落地方式

单文件主题层 `css/theme-v11.css`，在所有页面中**最后加载**（`3d.css` → `guide.css` → `theme-v11.css`），
通过 `:root` 覆写令牌 + 组件级规则收口，**不改任何 DOM 结构与交互逻辑**。

- 变量名与 v10 完全一致（`--acc/--gold/--gold2/--accent-ink/...`），因此 `guide.js` 写入的内联变量仍生效；
- 夜间模式只换表面（`--surface/--bg/--line`），强调色仍跟随用户所选皮肤；
- `guide.css` 中上一轮写死的夜间色（`#6EE7B7`、`#04241B`）已改为读令牌，避免两套主题层互相打架。

## 6. 实测验收（Playwright + Edge，1440×900，dpr=1）

**浅色模式 19/19 PASS**，最低 4.78:1：

```
.wm-h0 16.65 | .wm-subline 4.78 | .wm-hero-title 16.65 | .wm-count 4.78 | .wm-count b 8.79
.wm-layout 8.26 | .wm-layout.active 8.26 | select 17.92 | .wm-search 17.92 | .wm-card-name 17.92
.wm-card-meta 5.14 | .wm-empty h2 16.65 | .wm-empty p 4.78 | .wm-status 5.14
.wm-storage b 9.46 | .primary 6.18 | .ghost 17.92 | .gv-note-txt 17.92 | .gv-note-act 6.18
```

**夜间模式 17/17 PASS**，最低 6.18:1（`.primary`）。

顺带修掉两个真实缺陷：

1. **3D 画布不随窗口变大**：`render-pipeline.resize()` 读的是画布自身 `clientWidth`，
   而 `viewport.resize()` 调它时又没传参，形成闭环 → 画布永久停在初始 1280×720，右侧留白 160px。
   现由 `engine.resize()` 显式把容器尺寸传下去。
2. **夜间标题荧光绿**：`guide.css` 里 `body[data-fv-theme="night"] .wm-hero-title{color:#6EE7B7}`
   特异性高于新主题的 `.wm-hero-title`，导致深色底上出现荧光绿标题。

## 7. 已知取舍

- 3D 场景本身的光照与生态配色仍由 `engine.js` 时段与 `terrain` 生态控制，本轮**未改**，
  避免破坏「3A Q 版」的明亮基调；UI 与场景的衔接靠 `--bg` 与面板半透明解决。
- 主题层依赖 `:has()`（世界数为 0 时隐藏新建卡、提示避让）。Edge 105+ / Chrome 105+ 可用；
  Firefox 121+ 可用；更低版本仅退化为「双 CTA 同时出现」，不影响功能。
