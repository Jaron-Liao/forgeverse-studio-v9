# ForgeVerse × WorkBuddy 绿色主题规范（v10）

> 单一真相源。所有 UI / 场景 / 光照 / 图标改动只引用本文件色值。
> 目标：WorkBuddy 品牌绿为主，清爽、专注、专业；保留四生态场景识别度与全部 DOM/功能结构。

## 1. WorkBuddy 绿色基因
- 品牌核心：翠绿 `#10B981` / 深墨绿 `#065F46` / 薄荷浅绿 `#D1FAE5`。
- 气质：清爽、高效、可信（工具感 > 游戏化花哨）；绿色是"通行/成功/创造"的语义色。
- 比例：**65% 白绿底 / 25% WorkBuddy 翠绿 / 10% 辅助色（青蓝/琥珀/樱粉，仅状态与生态点缀）**。
- 禁止：大面积暖橙、紫罗兰主色、纯黑阴影、高饱和撞色堆砌。

## 4. 物体/材质
- 基础几何体：球 `0x34D399`、胶囊 `0x6EE7B7`、锥 `0xFBBF24`、柱 `0x7DD3FC`、环 `0xF9A8D4`。
- PBR 12 预设名称不变：金/银/铜仍金属色，玻璃/陶瓷提亮，霓虹改青绿 `0x06B6D4`。
- 赛博建筑/路面/装饰：统一青绿系（替代原紫罗兰），霓虹描边用 `--jade`/`--mint`。

## 5. 天空/光照
- zenith：`hue 0.44, sat 0.50, light 0.16+day*0.36`（青蓝天，绿系协调）。
- horizon：低角度暖 `hue 0.10` / 白天青 `hue 0.47`，light 提亮。
- 半球光：天空 `0xD6F5E8` / 地面 `0xFFF4DC`；轮廓光 `0xBFE4FF`；暖补光 `0xFFE8C0`。
- exposure `0.70+day*0.20`（上限 0.90）；Bloom threshold 1.35 / strength 0.28（不变，防过曝）。
- engine 初始背景 `0xE6F5EE`（淡绿白），地面 `0xE8F4EC`。

## 6. 专注模式（一次性跳过）
- 顶栏常驻开关 `#v10-focus-toggle`（按钮，aria-pressed），快捷键 `F9`。
- 开启后：① `toast()` 全局静默（state.js 内 early-return）② helpModal 禁止自动弹 ③ 隐藏所有 `.v9-hint`/引导气泡。
- localStorage 键 `v10.focus`，持久化；用户主动触发的 confirm/prompt 保留（不是干扰）。
- 关闭按钮上明确文案「专注模式 · 跳过所有提示」，开启时显示对勾态。
