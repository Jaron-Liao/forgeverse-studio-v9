# ForgeVerse 3A Q 版明亮配色规范（v9.2）

> 单一真相源。所有 UI / 场景 / 光照改动**只准引用本文件色值**，不得自行发明新色。
> 原则：明亮高饱和、层次清晰、精致可爱；保留四生态识别度与原有 DOM/变量结构，只换色值。

## 1. 色彩比例（60/30/10）
- **60% 中性底**：暖象牙白 + 半透明白面板（干净画布，衬托内容）
- **30% 主色**：暖橙金（延续"金"的品牌识别，由暗金提亮为活泼橙金）
- **10% 强调色**：薄荷绿 / 青玉蓝 / 樱粉 / 紫罗兰（按状态与生态分配，单点使用）

禁止：纯黑阴影（用彩色柔阴影）、大面积深紫底（cyber 仅生态场景内）、低饱和灰蒙蒙。

## 4. 物体/材质色（js/objects.js、js/materials.js）
- 基础几何体沿用明快色：球 `0xFFC85C`、胶囊 `0x8FE0A0`、锥 `0xFF9E6B`、柱 `0xB49BF5`、环 `0xFF9FC4`。
- 12 种 PBR 预设保持名称不变，整体提亮一档、饱和度 +15%，金属不再死灰。

## 5. 天空/光照（js/realism.js、js/lighting.js、js/environment.js）
- 天空 zenith：亮天蓝 `hue 0.55, sat 0.55, light 0.12+day*0.38`（比当前更亮更蓝，去暗紫）。
- horizon：暖色 `hue 0.08`（低角度）/ `0.54`（白天），light 提亮。
- 半球光天空色 `0xDCEEFF` / 地面色 `0xFFE6C4`（暖反射）。
- 补光：轮廓光 `0xBFE4FF`、暖补光 `0xFFE0B0`，强度略降避免过曝（明亮底色不需要强补光）。
- exposure：`0.72 + day*0.20`（上限 0.92，配合亮底色）。
- Bloom：threshold 1.35 保持（防过曝），strength 0.28（比当前更低，亮场景不需要强辉光）。
